# Starter collection image sources

These are static, locally served TMDB poster thumbnails and one backdrop, downloaded on 2026-10-17 for the Streambert web migration. Browsing this starter collection does not contact TMDB image servers. Artwork belongs to its respective copyright holders. TMDB provides image hosting; this project is not endorsed or certified by TMDB.

Catalog IDs use the same TMDB convention as the upstream `src/utils/api.js`. The collection is curated, not a live trending list. Plot descriptions were written for this starter collection. Display scores are fixed editorial sample values, not live TMDB scores. Years, runtimes, and season counts are static starter metadata and may require updates.

Each downloaded URL returned HTTP 200 and `image/jpeg`, JPEG signatures were verified, and the images were visually checked. Posters use TMDB's 342 px size; the backdrop uses 1280 px.
